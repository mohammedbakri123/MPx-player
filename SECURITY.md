# Security Policy

## Supported versions

Only the latest release is supported. Older APKs may contain bugs already fixed — please update and re-test before reporting.

Latest release: https://github.com/mohammedbakri123/MPx-player/releases/latest

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report it privately via GitHub: open a [private vulnerability report](https://github.com/mohammedbakri123/MPx-player/security/advisories/new) (Security tab → Report a vulnerability), or contact the maintainer through GitHub.

Include: what the issue is, where it is (file / screen / version), and steps to reproduce if you have them. You don't need a full exploit.

The maintainer will confirm receipt, fix it, and credit you in the release notes if you want.

## What counts

- Anything that leaks files, cookies, credentials, or download history outside the app
- Anything that lets a downloaded file or a played file run code it shouldn't
- Anything that bypasses Android permissions the app declares

General crashes and playback bugs are not security issues — file those as normal bug reports.
