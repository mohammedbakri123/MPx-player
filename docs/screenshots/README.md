# Screenshots

Real phone screenshots of the current app go here. Please don't reuse the old desktop mockups from November — they show an early design, not v0.3.5.2.

## What we need

- Phone screenshots, portrait, 1080x1920 or similar — no emulator frames, no desktop windows
- Player screen, Library / Local, Music, and Download tab are the priority
- No personal files, names, or videos visible — use sample files or blur titles

## How to add them

1. Take screenshots on your phone (volume down + power, or your phone's gesture).
2. Copy them here as:
   - `docs/screenshots/player.png`
   - `docs/screenshots/library.png`
   - `docs/screenshots/music.png`
   - `docs/screenshots/download.png`
3. Reference them in `README.md` under Screenshots, e.g.:

```md
![Player](docs/screenshots/player.png)
![Library](docs/screenshots/library.png)
```

Keep files under ~500 KB each (compress / resize if needed) so the repo stays light.
