# MPx Player — Telegram group

GitHub Discussions is for feedback and bugs that need to stay searchable. Telegram is for quick chat: "does this work on your phone?", screenshots, and release news. Keep bug reports with steps + device info on GitHub — they get lost in chat.

## Step 1: Create the group (5 minutes, on your phone)

1. Telegram → New Group → name it **MPx Player**
2. Group type: **Public**, username: try `mpxplayer` — if taken, `mpx_player` or `mpxplayerapp`. Pick whichever is free; don't pay for a username.
3. Description — paste this (edit the link once the group exists):

> MPx Player — free open-source Android media player, built on mpv.
> Try it: https://github.com/mohammedbakri123/MPx-player/releases/latest
> Feedback & bugs: https://github.com/mohammedbakri123/MPx-player/discussions
> English + العربية welcome. Be kind, no piracy, no spam.

4. Settings:
   - New members see history: **on** (so they see the pinned post)
   - Slow mode: **off** for now, turn on if spam starts
   - Add 2–3 admins you trust later — don't make strangers admins on day one
   - Enable "Approve new members" only if spam becomes a problem

## Rules (post these in the group description or as a second pinned message)

1. Be kind. No insults, no harassment.
2. No piracy — no cracked apps, no paid APKs, no links to stolen content. Talking about downloading a video you own is fine; sharing pirated movies is not.
3. Bugs go to GitHub Issues with device + version. Chat here is for quick questions and discussion.
4. No spam, no ads, no crypto, no "DM me" offers.
5. Don't share private files, cookies, or logins — ever.
6. English or Arabic, both welcome.

First offence: warning + message deleted. Repeat: ban. The maintainer's decision is final.

## Step 3: After the group exists

1. Copy the group link (`t.me/mpxplayer` or whatever you got).
2. Update these two places with the real link:
   - `README.md` → Community → "Telegram group"
   - `.github/ISSUE_TEMPLATE/config.yml` → Telegram contact link (replace the docs link with the real `t.me/...` link)
3. Announce it once in Discussions: "Telegram group is open — [link]".
4. Post each new release in the group with 3 lines: what's new, what to test, link to the release.

## Weekly routine (15 minutes)

- Monday: reply to unanswered questions in the group + Discussions.
- On release day: post the release in the group, ask one specific question ("Is scrolling smoother for you now?").
- Once a month: pin a "What should I fix next?" poll with 3–4 options from open issues.

## What NOT to do

- Don't create a Discord, a forum, and a Telegram group at the same time — one empty room kills momentum faster than no room. Telegram first; add Discord only if contributors ask for it.
- Don't post the group link in random groups as spam. One launch post in the right places beats ten spam posts.
