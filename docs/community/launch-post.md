>
> What it does:

> - Built-in downloader: yt-dlp with auto-update, quality settings, aria2c, audio-only, playlists, SponsorBlock, files to public Downloads/MPx

## What to do with replies

- Bug with device + steps → "Thanks — can you file it here so I don't lose it? [Issues link]" and file it yourself if they won't.
- "Does it do X?" → answer honestly. "Not yet, it's in #___" beats a vague promise.
- Feature idea → "Good idea — can you add it to Discussions so others can vote?"
- Harsh feedback → thank them, ask what phone/version/file. Don't argue.
